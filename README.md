# Nairaview

Nigerian Exchange (NGX) market information website — newly listed stocks, market news, stock performance and live charts.

- Live site: https://nairaview.meetomidiora.workers.dev
- Single-file static site (`index.html`), deployed on Cloudflare (Workers).
- Market data snapshot dated 25 Sep 2026; live ticker via embedded no-key widget.

Informational only — not investment advice.
